# 🚀 Rocket Manager
 
Sistema de gestão de projetos desenvolvido com Spring Boot no backend e Angular no frontend, com autenticação JWT e controle de acesso por perfis de usuário.

---

## 📋 Sobre o projeto
 
O Rocket Manager é uma aplicação fullstack que permite o gerenciamento de projetos, equipes e colaboradores. Cada tipo de usuário tem permissões específicas dentro do sistema, garantindo segurança e organização no fluxo de trabalho.
